# ポモドーロ ToDo

ポモドーロタイマーとToDoリストが一体になった、ブラウザだけで動くシンプルなアプリです。

## 使い方

`index.html` をブラウザで開くだけで動作します。インストールやビルドは不要です。

1. タスクを入力して「追加」でToDoリストに登録
2. タスクをダブルクリックすると「集中中」のタスクとして設定できます
3. 「開始」でタイマーを開始(25分の集中 → 5分の小休憩を4回繰り返した後に15分の長休憩)
4. タイマーが集中タイムを完了すると、集中中のタスクの🍅カウントが増えます

## 機能

- 集中(25分) / 小休憩(5分) / 長休憩(15分)を自動で切り替えるポモドーロタイマー
- タスクの追加・完了・削除
- タスクごとの完了ポモドーロ数の記録
- ToDoリストはブラウザの `localStorage` に保存され、再読み込みしても残ります
- タイマー完了時のブラウザ通知(通知を許可した場合)

## 技術

HTML / CSS / JavaScript のみで作られており、外部ライブラリへの依存はありません。
